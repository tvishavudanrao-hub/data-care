# Data Care brand

Client-facing look for the website, /tickets and client emails. The live ops board keeps its own dark theme.

## Logo
- `datacare-mark.svg` / `.png`: the puzzle piece in the gradient, for white or light backgrounds.
- `datacare-mark-white.svg`: the white piece, for use on the gradient.
- `datacare-app-icon.svg` / `.png` (512 px): white piece on a gradient tile (dock, phone, favicon).
- `datacare-wordmark.png`: the piece next to "Data Care" in Inter 600, for headers.

Keep clear space of at least half the mark's width around it. Don't recolor, rotate or outline the piece.

## Colors
| Use | Value |
|---|---|
| Gradient (135°) | #FF8A1F → #F2557A (52%) → #7B3FE4 |
| Ink | #141414 |
| Body text | #4A4A4A |
| Page | #FBF8F6 |
| Cards | #FFFFFF, border #ECE6E1 |
| Accent word, labels | #B4470F |
| Success | #13795B on #E6F4EE |

## Type
- Interface and body: Inter 400, 500, 600. Email fallback: Helvetica, Arial, sans-serif.
- Headlines: Instrument Serif 400, one italic word allowed. Fallback: Georgia.

## Shapes and spacing
- Buttons: #141414 with white text, 10px radius (pills 999px), at least 44px tall.
- Cards: 12 to 14px radius, 1px #ECE6E1 border, no shadows.
- Spacing on an 8px grid.

## Result labels
Every result gets exactly one: Recovered (#0F5F47 on #E6F4EE), Reconstructed and tested (#8A3409 on #FFF1E4), Reconstructed but untested (#5B2BB0 on #F4EEFF), Unresolved (#4A4A4A, dashed border).
